# Dwij Bhatt: personal website

## Files
- `index.html`: home page (about, resume, projects, contact)
- `research.html`: full research paper on medical device cybersecurity
- `style.css`: shared styles
- `resume.pdf`: one-page resume (the "Download resume" button links to it)

## Before publishing
1. Search both HTML files for `[ADD` and replace every yellow placeholder with real information.
2. Remove the `<span class="ph">` wrapper around each filled-in placeholder so the yellow highlight disappears.

## Deploy to Netlify (about 2 minutes)
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. Netlify gives you a live URL. Sign in to keep the site and rename it (for example, `dwijbhatt.netlify.app`).
4. To update later, drag the updated folder onto the site's "Deploys" tab.
